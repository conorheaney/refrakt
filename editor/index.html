How to edit paths

Snakes

Draw a snake head first, then back along where its body lies. Large handle: the head (its side of centre sets which way it strikes). Hollow: the tail. Dashed ring: its reach.

How to edit paths

Icicles

Draw along the underside of the scenery: icicles grow down from the line. Red dashes: the top of the highest bricks. Drag a diamond (an icicle) along the line to pin them all; Even spacing frees them.

How to edit paths

Scarab nests

Draw the entry point (large: where scarabs appear, behind the scenery), then the path they walk in along; the hollow last point is where they reach the floor.

How to edit paths

Dust

When the tomb rumbles, dust and grit pour from this line: draw it along the underside of the scenery (a lintel, an arch). Worlds with tomb dust need one to be played.
